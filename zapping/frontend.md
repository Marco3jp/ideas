# フロントエンド設計

## 技術スタック

| 項目 | 選定 | 理由 |
|------|------|------|
| フレームワーク | Next.js 15 (App Router) | SSR 不要だが、API Routes を同梱できるので MVP 段階では monorepo 的に使える |
| 言語 | TypeScript | |
| スタイリング | Tailwind CSS + shadcn/ui | 個人ツールとして素早くUIを組める |
| 状態管理 | Zustand | 軽量・シンプル。Redux は過剰 |
| HTTP クライアント | SWR + fetch | キャッシュ・再取得の自動管理 |
| パッケージマネージャー | pnpm | |

## プレイヤーブリッジ実装

各サービスの iframe / audio 要素を統一インターフェイスで操作するため、
**PlayerAdapter パターン**を採用する。

```typescript
interface PlayerAdapter {
  load(episode: Episode): Promise<void>;
  play(): Promise<void>;
  pause(): Promise<void>;
  seek(seconds: number): Promise<void>;
  setPlaybackRate(rate: number): Promise<void>;
  getDuration(): Promise<number>;
  getCurrentTime(): Promise<number>;
  onEnded(callback: () => void): void;
  onError(callback: (err: Error) => void): void;
  requestFullscreen(withComment?: boolean): void;
  destroy(): void;
}
```

### 実装クラス

| クラス | 対象 | 手法 |
|--------|------|------|
| `YouTubePlayerAdapter` | YouTube | YouTube IFrame Player API (postMessage) |
| `AudioPlayerAdapter` | Podcast | `<audio>` 要素の直接操作 |
| `ProxyPlayerAdapter` | 将来: Radiko 等 | バックエンドプロキシ経由 |

### YouTube IFrame Player API の利用

```typescript
// YT.Player を生成し、onStateChange で ENDED を検知
const player = new YT.Player(iframeId, {
  events: {
    onStateChange: (event) => {
      if (event.data === YT.PlayerState.ENDED) {
        onEnded();
      }
    },
  },
});
```

## ザッピング機能 UI

再生開始時にタイマーをセットし、設定時間（デフォルト: 30分）経過後に
「続きを見る？」オーバーレイを表示する。

```
┌──────────────────────────────────────┐
│  このまま次の動画に移ります           │
│                                      │
│  ████████████████░░░░░  8秒          │
│                                      │
│  [続きを見る]   [今すぐ次へ]         │
└──────────────────────────────────────┘
```

- ユーザーが「続きを見る」を押すとタイマーリセット
- タイムアウトまたは「今すぐ次へ」で次エピソードへ
- 見終わり（`onEnded`）を検知した場合はオーバーレイなしで即次へ

## チャンネル管理画面

### チャンネル登録フォーム

| フィールド | 内容 |
|-----------|------|
| URL / チャンネル ID | YouTube URL または RSS フィード URL を貼り付けるだけで自動判定 |
| 表示名 | 自動取得（手動上書き可） |
| 順序ポリシー | 新着優先 / 古い順優先 |
| 有効 / 無効 | チャンネル単位で無効化 |

### エピソード一覧

チャンネルごとにエピソード一覧を表示し、各エピソードに以下の操作を提供:

- 再生除外（disabled）トグル
- キューへ手動追加

## 再生設定

| 設定項目 | デフォルト値 | 備考 |
|---------|------------|------|
| ザッピング間隔 | 30 分 | 0 で無効（見終わるまで再生継続） |
| デフォルト再生速度 | 1.0x | |
| User-Agent | ブラウザ既定 | バックエンドプロキシ経由フェッチ時に使用 |
| 次エピソード猶予時間 | 10 秒 | ザッピングオーバーレイの表示時間 |

## エラーハンドリング

| エラー | 対応 |
|--------|------|
| iframe 読み込み失敗 | エラー表示 + キューから除外して自動で次へ |
| API 応答なし | リトライ（SWR の自動再取得） + トースト通知 |
| キュー空 | 「コンテンツがありません」画面 + チャンネル追加へ誘導 |
| 見終わり検知不可（YouTube 制限等） | ザッピングタイマーで代替 |

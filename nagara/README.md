# nagara — ずっと声を流し続けてくれるツール 設計ドキュメント

Issue #32 で提案された「ずっと声を流し続けてくれるツール」の設計をまとめたもの。
プロダクトの内部コードネームとして仮に **nagara**（ながら聴き）と呼ぶ。
将来正式名称が決まったら置き換える。ディレクトリ名・パッケージ名は外部公開を想定していないので、
気軽にリネームして問題ない。

## このドキュメントのスタンス

- Issue 本文にあるとおり、**最高のイメージはまだ未検証の想像である**ため、
  最初に分厚い設計を固めるのではなく **ミニマムに作って触ってから本設計に落とす** 方針を取る。
- そのため、本設計書では「**MVP で必ず作るもの**」と「**MVP では作らないが、想定として残しておくもの**」を
  はっきり分ける。
- 各種サービス（YouTube / Podcast / Radiko / TVer 等）の実現可能性は、
  想像ではなく公式仕様または既存実装の挙動を確認した上で記述する（[02-research.md](./02-research.md) に根拠をまとめた）。

## 一行サマリ

- ローカルネットワーク内に置く Linux PC（または Windows PC）で常駐させ、
  ブラウザから YouTube の埋め込みプレイヤーと Podcast の `<audio>` を順繰りに再生し続けるツール。
- 元になる動画／音声情報の取得は **API キー不要の公式 RSS（YouTube `feeds/videos.xml` と Podcast RSS）** を起点に始める。
- まず YouTube + Podcast の 2 ソースだけで MVP を作り、Radiko / TVer / コメント連動などは
  触りながら必要性を判断して順次足していく。
